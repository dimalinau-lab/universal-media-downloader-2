## Что нового в ветке Alpha (v3.2)

- **Интерактивный Telegram-бот (Inline-клавиатура)**: выбор озвучки, качества видео (1080p, 720p, 480p...) и серий/сезонов прямо в чате Telegram с помощью интерактивных кнопок для онлайн-кинотеатров (KinoPub / Rezka) и аниме (AnimeGO).
- **Структурированные настройки с Fluent Design**: полный отказ от эмодзи в интерфейсе настроек в пользу нативных Fluent-иконок Windows 11, информативные подсказки с комфортной задержкой отображения (2 секунды).
- **Интеграция MediaInfo и аудиоконвертера в карточки**: прямой вызов просмотра медиаинформации (кодеки, битрейт, дорожки) и быстрого извлечения/конвертации звука из контекстного меню карточки завершенной загрузки.
- **Предпочтение видеокодеков (H.264 / AV1 / VP9)**: выбор между максимальной совместимостью со старыми ТВ и плеерами (H.264/AVC) и повышенной эффективностью сжатия (AV1/VP9).
- **Диагностика системы и сети**: встроенный блок проверки окружения в настройках (статус Deno, FFmpeg/FFprobe) с быстрой командой установки Deno и онлайн-тестом сетевой задержки (ping) к YouTube, VK, RuTube, KinoPub/Rezka.
- **Визуальный Drag & Drop оверлей**: полупрозрачный индикатор сброса при перетаскивании веб-ссылок и текстовых файлов со списками URL (`.txt`).
- **Автоотправка файлов в Telegram**: Telegram-бот теперь автоматически присылает скачанные по запросу аудио/видео файлы (<50 МБ) обратно в личный чат.
- **Планировщик загрузок (Scheduler)**: возможность отложить старт загрузки по таймеру (через заданное время) или назначить точное время старта с автоматическим выполнением очереди и таймером завершения работы ПК.
- **Встроенный аудиоконвертер (Audio Converter)**: инструмент для конвертации скачанных или локальных видео/аудио файлов в форматы MP3, AAC, FLAC, WAV, OGG с гибкой настройкой битрейта (до 320 kbps).
- **Пакетное добавление ссылок (Batch URL Import)**: удобное окно для массовой вставки и добавления списков URL из буфера обмена или текстовых файлов.
- **Инспектор метаданных (Media Info)**: глубокий просмотр параметров медиафайлов через FFprobe (видео/аудио кодеки, разрешение, битрейт, длительность, каналы).
- **Специализированные экстракторы медиа**:
  - **AnimeGO**: парсинг серий, озвучек и плееров (Kodik, Aniboom, Alloha) с выбором качества.
  - **Pinterest**: прямое извлечение медиафайлов и видео высокого разрешения.
- **Расширенный файловый менеджер (Files Tab)**: фильтрация файлов по категориям (видео, аудио, картинки, архивы), быстрый поиск, сортировка, контекстное меню с конвертацией, просмотром медиаинфо и удалением.
- **Очистка архитектуры**: полное удаление устаревшего расширения браузера и Local API в пользу нативного интерактивного взаимодействия через Telegram и десктопный GUI.
- **Новые параметры загрузки**: настройка ограничения скорости, выбор формата по умолчанию, оптимизированное управление потоками.
- **Обновление локализации**: добавлены и актуализированы ключи локализации (RU, EN, UK) для всех новых функций и диалоговых окон.

## Возможности

- **Поддержка платформ**: YouTube, TikTok, Instagram, VK, RuTube, Twitch (VOD и Live), Kick, AnimeGO, Pinterest, vi3000.top (Lampa), Kinopoisk, KinoPub / Rezka и многие другие сервисы.
- **Интерактивный выбор серий и озвучки**: встроенные окна настроек для кинотеатров и аниме с возможностью пакетной загрузки сезонов.
- **Планировщик загрузок**: запуск задач по таймеру или в установленное расписание с опцией автовыключения ПК.
- **Пакетный импорт ссылок**: массовое добавление списков URL из текста или буфера обмена.
- **Встроенный аудиоконвертер**: быстрое извлечение и перекодирование звуковых дорожек в MP3, AAC, FLAC, WAV, OGG.
- **Инспектор Media Info**: технические характеристики любого медиафайла через встроенный FFprobe.
- **Удаленное управление**: встроенный Telegram-бот с inline-кнопками для выбора параметров контента и обратной отправкой готовых файлов.
- **Встроенная визуальная обрезка**: нарезка видеофайлов прямо внутри приложения.
- **Выбор качества и кодеков**: индивидуальные настройки разрешений для платформ и приоритет кодеков (H.264 / AV1 / VP9).
- **Параллельные загрузки**: настраиваемое число одновременно скачиваемых файлов.
- **История загрузок**: удобный список всех ранее загруженных медиа.
- **Субтитры**: автопоиск и вшивание дорожек субтитров (RU, EN, UK).
- **Cookies**: авторизация через `cookies.txt` или автоматический импорт куков из браузеров (Chrome, Edge, Opera, Firefox и др.).
- **Drag & Drop**: перетаскивание ссылок и `.txt` списков прямо в окно программы с визуальным оверлеем.
- **Темы оформления**: плавная смена светлой и тёмной тем Fluent Design.
- **Локализация**: полная поддержка русского, английского и украинского языков.
- **Автообновление ядра**: фоновая проверка свежих версий yt-dlp при запуске.

## Удаленное управление через Telegram-бота

Приложение оснащено встроенным автономным Telegram-ботом для удаленного управления загрузками со смартфона или любого другого устройства:

1. **Подключение**: Введите токен бота (создается через [@BotFather](https://t.me/BotFather)) на вкладке «Telegram» или в «Настройках».
2. **Обычные ссылки**: Отправьте боту прямую ссылку (YouTube, VK, RuTube и др.) — программа мгновенно добавит задачу в очередь загрузок на ПК.
3. **Интерактивный выбор серий и озвучек (Inline-кнопки)**: При отправке ссылки на фильм, сериал или аниме (KinoPub, HDRezka, AnimeGO) бот присылает сообщение с интерактивными кнопками прямо в диалог:
   - **Шаг 1**: выбор студии озвучки (Дубляж, LostFilm, AniLibria, TVShows и др.);
   - **Шаг 2**: выбор качества видео (1080p, 720p, 480p...);
   - **Шаг 3**: выбор конкретной серии или скачивание всего сезона / фильма целиком.
4. **Обратная отправка**: Если размер готового медиафайла не превышает 50 МБ, бот автоматически отправит файл обратно в ваш чат в Telegram.

## Особенности работы с онлайн-кинотеатрами

### Задержка 10–20 секунд при добавлении KinoPub / Rezka
При добавлении ссылки с KinoPub или Rezka приложение может кратковременно показывать статус: *«Обход защиты сайта и поиск серий...»*.

**Это нормальный рабочий процесс:**
1. Для обхода защиты сайта (Cloudflare / антибот-проверки) программа в фоне открывает скрытый экземпляр браузера (Edge Chromium).
2. Скрипт получает cookies сессии, считывает список доступных озвучек, сезонов, серий и доступные разрешения видео.
3. Как только фоновая прогрузка завершается, открывается окно, в котором можно выбрать озвучку, сезон, серию или отправить на скачивание весь сезон целиком.

### Скачивание с vi3000.top (Lampa / Cub)
1. Вставьте ссылку на `vi3000.top` в поле ввода программы.
2. Автоматически откроется окно браузера с интерфейсом кинотеатра.
3. Перейдите к нужному фильму или сериалу, выберите подходящую озвучку, сезон, серию и качество.
4. Нажмите «Play» (запустите воспроизведение в плеере).
5. Программа автоматически поймает поток, добавит файл в очередь загрузок и сама закроет вспомогательное окно браузера.

## Установка

Готовые дистрибутивы для Windows можно скачать на странице [Releases](https://github.com/dimalinau-lab/universal-media-downloader-2/releases):

### 1. Установщик (Installer)
- Скачайте **`Universal_Media_Downloader_v3.2_Setup.exe`**.
- Запустите файл для автоматической установки с созданием ярлыков в меню «Пуск» и на рабочем столе, а также удобным деинсталлятором.
- Не требует прав администратора для базовой установки.

### 2. Портативная версия (Portable)
- Скачайте архив **`Windows_UMD_v3.2_Portable.zip`**.
- Распакуйте архив в любую папку или на USB-носитель и запустите `Windows3.2.UMD.exe`.
- Все настройки, очереди и кэш сохраняются автономно в локальной папке программы (`data/`), не требуя прав администратора и не затрагивая реестр Windows.

## Требования для запуска из исходного кода

- **Python** 3.11+
- **Deno** 2.0+ (рекомендуется для обхода JS-челленджей YouTube)

### Установка Deno (для YouTube)

**Windows (PowerShell):**
```powershell
irm https://deno.land/install.ps1 | iex
```

### Встроенный FFmpeg
**Устанавливать FFmpeg вручную не требуется!** Приложение уже содержит все необходимые встроенные бинарные файлы в папке `assets/ffmpeg/bin/`.

## Установка из исходного кода

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/dimalinau-lab/universal-media-downloader-2.git
cd universal-media-downloader-2
```

2. **Создайте и активируйте виртуальное окружение:**
```bash
python -m venv .venv
.venv\Scripts\activate
```

3. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

4. **Запустите приложение:**
```bash
python main.py
```

## Использование

1. Вставьте ссылку в поле ввода и нажмите Enter или кнопку «+».
2. Настройте качество и кодеки в разделе «Настройки» (при необходимости).
3. Нажмите «Скачать все».

### Способы добавления ссылок:
- Вставка ссылок через интерфейс или горячие клавиши.
- Drag & Drop ссылок или `.txt` файлов со списком URL прямо в окно приложения с визуальным оверлеем.
- Отправка ссылок в Telegram-бота с мобильного телефона с обратной отправкой готового файла.
- Пакетное добавление списка URL через кнопку «Пакетный импорт».

## Зависимости

- **PyQt6** — современный GUI фреймворк
- **PyQt-Fluent-Widgets** — компоненты в стиле Windows 11 Fluent Design
- **yt-dlp[curl-cffi]** — продвинутый мультиплатформенный движок загрузки
- **selenium & webdriver-manager** — автоматизация браузера для обхода защит кинотеатров
- **beautifulsoup4** — парсинг страниц и медиаданных
- **requests** — сетевой HTTP-клиент
- **pyTelegramBotAPI** — интеграция с Telegram для удаленного управления
- **packaging** — проверка и сравнение версий
