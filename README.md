## Исправленные ошибки

В версии 3.3 устранены ключевые проблемы стабильности и совместимости:

- **Гарантированное скачивание MP3**: Исправлена ошибка, из-за которой не всегда скачивался MP3 — при выборе формата MP3 для некоторых онлайн-кинотеатров и прямых видеопотоков скачивался видеофайл вместо звуковой дорожки. Теперь при выборе MP3 гарантированно формируется чистый аудиофайл MP3 (320 kbps) с автоматической очисткой временного видео.
- **Свободное переключение качества (устранение блокировки на 360p)**: Исправлена ошибка, когда при первоначальном выборе низкого разрешения (например, 360p) меню качества блокировалось и не позволяло переключиться обратно на высокое (1080p). Теперь для всех видео и серий всегда доступен полный список разрешений (1080p, 720p, 480p, 360p) и MP3.
- **Корректный запуск после установки**: Устранена системная ошибка инсталлятора (код 740, требование повышения прав) при финальном запуске программы. Приложение корректно стартует от имени текущего пользователя.
- **Сохранение видео в разных разрешениях без перезаписи**: Ранее при повторной загрузке одного и того же видео или серии в другом качестве (например, сначала в 360p, а затем в 480p) старый файл перезаписывался из-за одинакового названия. Теперь к имени файла автоматически прикрепляется маркер качества (`[360p]`, `[480p]`, `[720p]`, `[1080p]`, `[MP3]`). Все варианты сохраняются параллельно и отображаются в менеджере файлов с индивидуальными значками качества.
- **Безопасная работа с браузерами без сброса Discord**: Полностью исключено принудительное завершение процессов браузера (`taskkill`), вызывавшее закрытие окон Chrome и сброс соединения Discord. Для авторизации на YouTube и закрытых ресурсах используется безопасное теневое копирование сессии в фоновом режиме.
- **Стабильность прямых потоков (устранение сброса соединения)**: Устранена ошибка разрыва сетевого соединения (`WinError 10054 / ConnectionReset`) при скачивании прямых видеопотоков с серверов Kodik, AnimeGO и solodcdn. Реализован механизм предварительного экспресс-опроса параметров и прямой потоковый загрузчик.
- **Совместимость с HLS и M3U8 трансляциями**: Устранена ошибка «Requested format is not available» при загрузке серий со сторонних плееров. Реализован адаптивный селектор потоков с автоматическим переходом на универсальный резервный поток при недоступности основного.
- **Стабильное отображение размера файла**: Исправлено мерцание и сброс рассчитанного веса серии во время загрузки фрагментов или при объединении видео со звуковой дорожкой. Размер фиксируется до начала скачивания и сохраняется до завершения.
- **Защита от сбоев при отмене задач**: Предотвращено аварийное завершение приложения при быстрой остановке или удалении задачи из очереди во время сетевой активности.

## Ключевые возможности и улучшения

### 1. Загрузка и управление качеством
- **Быстрый выбор разрешения в карточке**: Переключение качества видео (от 360p до 4K) и режима извлечения звука (MP3) прямо из выпадающего меню на карточке задачи, с предварительным расчетом веса каждого варианта.
- **Интеллектуальная оценка размера**: Для онлайн-кинотеатров и HLS-манифестов приложение заранее рассчитывает реальный размер серии на основе битрейта и длительности.
- **Приоритет видеокодеков**: Возможность выбора предпочтительного кодека в настройках:
  - **H.264 (AVC)** — максимальная совместимость со старыми телевизорами, медиаплеерами и смартфонами;
  - **AV1 / VP9** — улучшенное сжатие и экономия дискового пространства при высоком качестве.
- **Встроенная обрезка по времени**: Точная нарезка фрагмента видео без необходимости полной загрузки всего ролика.

### 2. Поддержка онлайн-кинотеатров и сериалов
- **Пакетная загрузка сезонов**: Встроенные диалоговые окна для AnimeGO, KinoPub, HDRezka и vi3000.top (Lampa) с выбором озвучки, сезона и нужных серий.
- **Оригинальные логотипы платформ**: Полноцветные векторные и адаптированные логотипы сервисов для комфортной визуальной навигации.

### 3. Удаленное управление через Telegram-бота
- **Интерактивные кнопки в чате**: При отправке ссылки на сериал бот выводит кнопки для выбора студии перевода, качества и списка серий прямо в мессенджере.
- **Обратная отправка файлов**: Готовые аудио- и видеофайлы размером до 50 МБ автоматически пересылаются пользователю в ответном сообщении.

### 4. Встроенные медиаинструменты
- **Аудиоконвертер**: Быстрое преобразование любых скачанных или локальных файлов в форматы MP3, AAC, FLAC, WAV, OGG с битрейтом до 320 kbps.
- **Инспектор метаданных (Media Info)**: Просмотр технической информации о файле (разрешение, частота кадров, кодеки видео и звука, количество каналов) через встроенный модуль FFprobe.
- **Менеджер файлов**: Вкладка «Скачанные файлы» с фильтрацией по категориям (видео, аудио, архивы), мгновенным распознаванием качества и контекстным меню действий.

### 5. Автоматизация и интерфейс
- **Планировщик загрузок**: Запуск задач по расписанию или по таймеру с возможностью автоматического выключения ПК по окончании всех загрузок.
- **Drag & Drop**: Перетаскивание ссылок и текстовых списков (`.txt`) в окно программы с визуальной индикацией зоны сброса.
- **Строгий дизайн**: Полноценная поддержка светлой и темной тем оформления, аккуратные шрифты и отсутствие лишних визуальных элементов.

## Удаленное управление через Telegram

1. Создайте бота через официального [@BotFather](https://t.me/BotFather) и скопируйте полученный токен.
2. Откройте вкладку **«Telegram Бот»** в программе, вставьте токен и нажмите **«Запустить бота»**.
3. Отправьте боту команду `/start` с телефона.
4. Отправляйте ссылки на видео или сериалы:
   - Для одиночных видео загрузка начнется автоматически.
   - Для сериалов бот предложит выбрать озвучку и серии с помощью интерактивных кнопок.
   - Файлы размером до 50 МБ бот отправит обратно в чат.

## Работа с онлайн-кинотеатрами

### AnimeGO и Kodik
При вставке ссылки на страницу аниме программа автоматически опрашивает доступные плееры, формирует список серий с указанием озвучек и позволяет выбрать серию или скачать весь сезон целиком.

### KinoPub и HDRezka
Программа использует безопасный встроенный модуль для прохождения защиты сайта, считывает доступные переводы и сезоны, после чего открывает окно выбора серий.

### vi3000.top (Lampa)
При вставке ссылки открывается вспомогательное окно каталога. Достаточно запустить воспроизведение нужной серии — поток будет автоматически перехвачен программой, после чего окно закроется, а серия отправится в очередь загрузок.

## Установка и дистрибутивы

Готовые сборки для Windows доступны в папке `output/` и на странице релизов:

1. **Инсталлятор (`Universal_Media_Downloader_v3.3_Setup.exe`)**:
   - Автоматическая установка программы на компьютер.
   - Создание ярлыков в меню «Пуск» и на рабочем столе.
   - Корректная регистрация в системе и встроенный деинсталлятор.

2. **Портативная версия (`Windows_UMD_v3.3_Portable.zip`)**:
   - Не требует установки и прав администратора.
   - Распаковывается в любую папку или на съемный диск.
   - Настройки, история и сессии сохраняются локально в каталоге программы (`data/`).

## Сборка из исходного кода

### Требования
- **ОС:** Windows 10 / 11 (64-bit)
- **Python:** 3.11 или новее
- **FFmpeg:** Встроен в проект (папка `assets/ffmpeg/bin/`), дополнительная установка не требуется.
- **Deno:** Рекомендуется для работы с YouTube-плеером (`irm https://deno.land/install.ps1 | iex`).

### Порядок запуска

1. **Клонирование репозитория:**
   ```powershell
   git clone https://github.com/dimalinau-lab/universal-media-downloader-2.git
   cd universal-media-downloader-2
   ```

2. **Создание и активация виртуального окружения:**
   ```powershell
   python -m venv .venv
   .venv\Scripts\Activate.ps1
   ```

3. **Установка зависимостей:**
   ```powershell
   pip install -r requirements.txt
   ```

4. **Запуск приложения:**
   ```powershell
   python main.py
   ```

5. **Сборка исполняемого файла (PyInstaller):**
   ```powershell
   pyinstaller --distpath output Windows3.3.UMD.spec
   ```

6. **Сборка инсталлятора (Inno Setup):**
   ```powershell
   "D:\Inno Setup 6\ISCC.exe" installer.iss
   ```
